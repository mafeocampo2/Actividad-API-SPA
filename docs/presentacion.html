Agenda del Salón

Una app para que el dueño de un salón o spa maneje clientes, servicios y citas sin cruces de horario, y vea cuánto factura.

Frontend Expo + React Native Backend Express 5 + TypeScript Datos PostgreSQL + Prisma Hosting Render
01
El problema

La agenda en cuaderno se cruza, se pierde y no dice cuánto se ganó

Antes

Citas anotadas a mano o en WhatsApp. Dos clientes llegan a la misma hora y nadie sabe qué turnos quedan libres.

Con la app

El sistema calcula los turnos libres según la duración del servicio y rechaza cualquier cita que se cruce.

Resultado

Historial por cliente, cancelaciones con motivo y reportes de ingresos por rango de fechas.

03
Arquitectura del backend

Cada petición baja por capas: router, servicio, Prisma, PostgreSQL

Awilix crea cada servicio una sola vez y le inyecta la conexión a la base. Así cada capa se cambia o se prueba por separado.

04
Modelo de datos

Cuatro tablas, y la cita guarda una copia de lo que costó

Usuario · Cliente · Servicio

Contraseñas cifradas con scrypt. El email del cliente es único. Un servicio inactivo no se puede agendar.

Cita

Guarda nombre del cliente, del servicio y el precio del momento. Si después se edita o borra el cliente, el historial no cambia.

Ciclo de vida de una cita

PENDIENTE→ CONFIRMADA→ COMPLETADA NO_ASISTIO CANCELADA

Solo las citas pendientes o confirmadas se pueden reprogramar o cerrar. Las otras tres son estados finales.

05
Reglas de negocio

El backend hace cumplir seis reglas

  • 01
    HorarioLunes a sábado, 08:00 a 18:00, turnos cada 30 min
  • 02
    Sin crucesDos citas no ocupan el mismo horario (409)
  • 03
    Hora de ColombiaLos turnos ya pasados de hoy no se ofrecen
  • 04
    Estados finalesUna cita cerrada no se reprograma ni se reabre
  • 05
    Clientes con citasNo se borra un cliente con citas pendientes
  • 06
    IngresosSolo suman las citas completadas
06
API REST · /api/v1

17 endpoints, un solo formato de error

MétodoRutaQué hace
POST/auth/loginInicia sesión
GET · POST/clientesLista (con búsqueda) y registra clientes
GET · PUT · DELETE/clientes/:idFicha, edición y borrado; /citas da su historial
GET/serviciosCatálogo activo
GET/disponibilidadTurnos libres, ocupados, pasados o cerrados
GET · POST/citasLista con filtros y agenda (409 si se cruza)
PATCH/citas/:id[/estado|/cancelar]Reprograma, cierra o cancela
GET/dashboard/resumenResumen del día
GET/reportes/resumenIngresos y estadísticas por rango

Todo error responde { "code": "CONFLICT", "message": "…" } con su código HTTP: 400, 401, 404 o 409.

  3. Descargar con el enlace o el QR
